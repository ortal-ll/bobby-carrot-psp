# bobby-carrot-psp
BOBBY CARROT 1 PSP

ISO и EBOOT содержат одну и ту же игру; устанавливать оба не нужно.

УСТАНОВКА НА PSP С ПОДДЕРЖКОЙ HOMEBREW
Вариант 1: скопируй файл из папки ISO в /ISO на карте памяти.
Вариант 2: скопируй папку PSP/GAME/BCARROT в /PSP/GAME на карте памяти.
На физической PSP эта сборка ещё не проверена.

УПРАВЛЕНИЕ
Крестовина — движение и навигация.
Крестик — выбрать, повторить после поражения, перейти после победы.
Круг — назад из раздела; из главного меню — продолжить текущую игру.
START — пауза / продолжить.
Треугольник — повторить текущий уровень.
L / R — переключить морковь / яйца в выборе уровней и рекордах.
В правилах: влево / вправо — страницы, крестик — следующая.
Рисунки кнопок находятся в пункте «Управление» главного меню.
Стандартная раскладка PPSSPP: стрелки, Z (крестик), X (круг), S (треугольник), пробел (START), Q/W (L/R).

ПРОГРЕСС
Сохранения находятся в PSP/SAVEDATA/BCAR00001 на карте памяти.
Сохраняй всю эту папку при переносе на другое устройство.
